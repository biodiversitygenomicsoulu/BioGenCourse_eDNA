# R Shiny Applications for Teaching eDNA Metabarcoding

## 1. eDNAbler

<a href="https://pknichols.com/ednabler/">
  <img src="https://github.com/user-attachments/assets/53f06b10-ad09-4b65-93b3-2800c43412f6" alt="eDNAbler" width="150">
</a>

Planning tool for calculating maximum sampling effort based on sequencing depth. Explore how sample size, replication, and negative controls affect the maximum number of sites and samples that can be collected in the field.

## 2. Decontaminator

<a href="https://pknichols.com/decontaminator/">
  <img src="https://github.com/user-attachments/assets/6a491b8c-4570-4134-9685-9fa890fa33d5" alt="Decontaminator" width="150">
</a>

OTU table decontamination when using negative control samples in eDNA data. Upload an eDNA OTU table to filter contaminated reads using microDecon. Explore how tuning model parameters can alter the decontamination of eDNA.

## 3. eDNAdventure

<a href="https://pknichols.com/ednadventure/">
  <img src="https://github.com/user-attachments/assets/102d928a-bb05-4d2a-a86e-d592e959a382" alt="eDNAdventure" width="150">
</a>

Broad-scale exploration of eDNA data, species distributions, and read abundances. Upload a decontaminated OTU table with taxonomic information and a metadata file to view spatial and/or temporal patterns in your data!

## 4. HillYeah!

<a href="https://pknichols.com/hill-yeah/">
  <img src="https://github.com/user-attachments/assets/92f80830-9544-4e05-88eb-ae31d9c97f53" alt="HillYeah" width="150">
</a>

Explore rarefaction, sample diversity and coverage patterns. Explore diversity metrics using Hill numbers, rarefying samples to equal coverage/depth.
